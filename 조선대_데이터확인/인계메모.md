# 인계 메모 (카메라 실습 세션에서 넘어옴, 2026-10-28)

이 폴더는 "상황 맞춤 경로 도우미" 1주차 데이터 확인 결과입니다. 자세한 내용은 `데이터확인_조선대주변.md`에 있습니다.

## 파일
| 경로 | 내용 |
|---|---|
| `데이터확인_조선대주변.md` | 결론·표·빈 곳과 대책·다음 할 일 |
| `osm_check.py` | OSM 보행망 품질 지표 → `out/osm_stats.json`, `figs/osm_*.png`, `out/walk.graphml` |
| `route_test.py` | 무작위 300쌍 우회율 → `out/route_test.json` |
| `coverage.py` | 보안등·CCTV·편의점을 길 조각에 겹치기 → `out/coverage.json`, `figs/night_layers.png` |
| `raw/highway.osm`, `raw/points.json` | Overpass 원본 (범위 35.125~35.160, 126.915~126.950) |
| `raw/pubdata/` | 동구 보안등(UTF-8 BOM), 광주 CCTV(**CP949**), 상가정보 범위 부분(UTF-8 BOM), 남구 보안등(동별 합계) |

## 실행 환경 주의
- 가상환경: `python3 -m venv .venv && .venv/bin/pip install osmnx matplotlib pyproj` (osmnx 2.0.7, geopandas 1.0.1)
- 맥 기본 파이썬 3.9는 SSL이 오래돼 osmnx가 OSM 서버에 직접 못 붙습니다. 그래서 **curl로 받은 파일을 `graph_from_xml`로** 읽습니다. 받을 때는 User-Agent를 꼭 붙이세요. 안 붙이면 406 오류가 납니다.
- data.go.kr 제공기관 이름이 "전남광주통합특별시"로 바뀌었습니다.

## 핵심 숫자
- 보행망 253km, 98% 연결, 우회율 중앙값 1.23, 경로 실패 2.4%
- OSM `lit` 태그 0.3%: 조명은 공공데이터로만 판단
- 동구 길 중 보안등 30m 안 71.5%, CCTV 50m 안 54.2%, 편의점 50m 안 22.5%

## 빈 곳
- 큰길 가로등: 행안부 공통POI API, 서비스 키 필요
- 캠퍼스 안: 학교 조명 자료 없음

- 24시간 여부, 지구대·안심귀갓길: 없음
