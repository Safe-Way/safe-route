# 사용성 점검표 — 어르신·휠체어 사용자 대신 해 보기 (2026-11-06)

교수님 피드백: "잘 쓰는 사람이 아니라 불편한 사람 입장에서 쓰기 불편한 것을 찾아 고쳐야 한다."
팀원이 아래 역할을 맡아 실제 휴대폰으로 해 보고, 날짜별로 통과/실패를 적는다. 실패한 줄은 D파트에 넘긴다.

**역할 (하나씩 맡아 그 사람처럼 해 보기)**
- 75세 어르신: 돋보기 없이, 손가락이 굵고 조금 떨림, 영어·작은 아이콘 모름
- 휠체어 사용자: 한 손으로 휴대폰을 듦, 바깥(밝은 햇빛)에서 봄
- 보호자: 자녀가 부모님 대신 처음 설정해 줌
