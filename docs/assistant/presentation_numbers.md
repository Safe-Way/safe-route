## 2. 같은 출발·도착, 일반 길찾기와 다른 점 (밤 기준, 학교 서버)
| 출발 → 도착 | 가장 짧은 길 | 세잎지도가 고른 길 | 이유 (서버가 만든 문장 그대로) |
|---|---|---|---|
| 문화전당 → 양림동 펭귄마을 | 1,821m | 2,097m | 276m 더 돌지만 **가로등 +20개, CCTV +8대, 도움 지점 +3곳** |
| 문화전당 → 남광주시장 | 1,599m | 1,729m | 130m 더 돌지만 **가로등 +19개, CCTV +4대, 도움 지점 +4곳** |
| 동명동 → 문화전당 | 992m | 1,000m | 8m만 더 돌고 더 밝고 사람 눈이 닿는 길 |

같은 길이라도 **휠체어 모드는 걸음 속도가 달라** 시간이 다르다. 문화전당 → 양림동은 휠체어 42분, 노인 35분이다.

## 3. 비서가 기억해서 달라지는 것 (시연 게스트, 꾸민 기록)
| 시연 게스트 | 기록 | 비서가 하는 말 |
|---|---|---|
| A 휠체어 사용자 | 3주, 비 오는 날 6번 모두 버스, 걸음 속도 분당 46.9m(기본 50) | "비가 와서 버스를 추천해요. 지난번 비 올 때도 버스를 타셨어요." |
| A | 월~금 8시 반 문화전당 3번씩 | "8시 반에 문화전당 가시죠?" (먼저 말 걸기) |
| B 어르신 | 월·수·금 10시 남광주시장, 추운 날 버스 | "오늘은 추워서 버스가 나아요." |
| C 임시 휠체어 | 11-30까지 휠체어 | "화장실 어디야" → 장애인 화장실만 |

시연 기록은 **꾸민 값**이고 날씨도 시연용으로 정했다. 발표에서 이렇게 밝힌다.

## 4. 정직하게 밝힐 것
- 문화전당 1km 길 중 16%(381개)는 데이터가 부족해서 "확인 안 됨"으로 표시한다. 모른다고 안전하다고 치지 않는다.
- 보도턱 낮춘 횡단보도 데이터는 광주에 296곳뿐이다(동구 3곳). 경사 데이터는 없어 사용자 신고로 채운다.
- 사고·공사 정보(국가교통정보센터)는 차도 위주라 인도 공사는 신고로 받는다.
