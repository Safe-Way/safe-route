# 비서 대화 예시 10개 (초안, 2026-11-06)

비서(`POST /api/assistant`, 구글 제미나이 함수 호출)가 어떻게 답해야 하는지 정한 설계서이자 시험지다.
예시마다 **사용자 말 → 비서가 부를 도구 → 기대하는 답**을 적었다. 팀 회의에서 고치고 확정한다.

- 시연 게스트(`scripts/seed_demo.py`): **A** `…de01` 휠체어 사용자, **B** `…de02` 어르신(지팡이), **C** `…de03` 평소 일반인데 11-30까지 임시 휠체어
- 도구 7개: `search_place`, `recommend_trip`, `find_nearby`, `get_my_info`, `update_my_info`, `set_map_layers`, `report_problem`
- 규칙: 숫자·출구·버스 번호·시간은 도구 결과에서만 말한다. 저장하는 도구(`update_my_info`, `set_map_layers`, `report_problem`)는 먼저 확인을 받고 부른다. 도구 호출은 한 번 묻는 데 4번까지.
- 아래 숫자(분, 버스 번호 등)는 예시다. 실제 값은 그때 도구 결과로 바뀐다.

---

## 1. 휠체어로 목적지 (기본 장면)
- **누가·언제:** A, 화요일 8:25, 비
- **사용자:** "문화전당 가야 해."
- **도구:** `search_place("문화전당")` → `recommend_trip(도착=국립아시아문화전당, 모드=지금 모드)`
- **기대 답:** "오늘은 비가 와서 버스를 추천해요. 지난번 비 올 때도 버스를 타셨어요. 정류장까지 턱 없는 길로 4분이고, ○○번 저상버스가 ○분 뒤에 와요." + [이 길로 출발]
- **보는 점:** 모드를 묻지 않음(A는 휠체어로 저장됨). 이유에 날씨와 지난 기록이 들어감. 저상버스를 먼저 말함

## 2. 처음 쓰는 사람 (물어보며 설정)
- **누가·언제:** 새 게스트(setup_done = 0)
- **사용자:** "길 좀 찾아 줘."
- **도구:** `get_my_info` → (모름) → 묻기
- **기대 답:** "처음 오셨네요. 어떻게 다니세요? 걸어서, 지팡이, 휠체어, 유모차 중에 말씀해 주세요." → 답을 들으면 "계단은 몇 칸 괜찮으세요?" … (한 번에 하나씩, 5가지)
- **보는 점:** 한 번에 질문 하나. 답을 다시 읽어 주고 확인한 뒤 `update_my_info`

## 3. 몸 상태가 잠깐 바뀜 (언제까지)
- **누가·언제:** 평소 일반인 게스트
- **사용자:** "다리를 다쳐서 휠체어 타고 다녀."
- **도구:** (확인 뒤) `update_my_info(temp_mode=wheelchair, temp_until=?)` → `set_map_layers(장애인 화장실, 보도턱 낮춘 횡단보도, 같은 기간)`
- **기대 답:** "많이 불편하시겠어요. 언제까지 휠체어를 타세요?" → "이번 달 말까지" → "11월 30일까지 휠체어로 안내할게요. 그동안 장애인 화장실과 보도턱 낮춘 횡단보도도 지도에 보여 드릴까요?"
- **보는 점:** 기간을 꼭 물음. 모르면 "일주일 동안 휠체어로 하고 그때 다시 여쭤볼게요"

## 4. 가까운 화장실 (모드에 맞게)
- **누가·언제:** C (11-30까지 휠체어)
- **사용자:** "화장실 어디야?"
- **도구:** `find_nearby(kind=toilet, mode=지금 모드)`
- **기대 답:** "가장 가까운 장애인 화장실은 ○○로 ○m예요. 지금 열려 있어요." + [여기로 가기]
- **보는 점:** 평소 모드(일반)가 아니라 지금 모드(휠체어)로 찾음. 장애인 화장실만 나옴

## 5. 길 위 행사
- **누가·언제:** A, 11-07 오후 (금남로 차 없는 거리 행사 중)
- **사용자:** "충장로 쪽으로 가 줘."
- **도구:** `search_place` → `recommend_trip` (안에서 road_event 확인)
- **기대 답:** "금남로에서 '차 없는 거리' 행사가 열리고 있어 사람이 많아요. 휠체어로 지나기 편하게 옆길로 안내할게요. 2분 더 걸려요."
- **보는 점:** 행사 이름은 road_event에서. 일반 모드였다면 피하지 않고 알림만

## 6. 말로 신고
- **누가·언제:** B, 걷는 중
- **사용자:** "여기 공사 중이라 못 지나가."
- **도구:** (확인 뒤) `report_problem(type=construction, 지금 위치)` → `recommend_trip` 다시
- **기대 답:** "지금 계신 곳을 '공사'로 신고할까요? 사진도 찍으실래요?" → "네" → "신고했어요. 공사 구간을 피해서 다시 안내할게요."
- **보는 점:** 신고 전에 확인. 사진은 선택. 신고 뒤 바로 다시 안내

## 7. 지도에 보일 것 바꾸기
- **누가·언제:** A
- **사용자:** "엘베 있는 육교도 보여 주고, CCTV는 빼 줘."
- **도구:** (확인 뒤) `set_map_layers(더하기=엘리베이터 육교, 빼기=CCTV)`
- **기대 답:** "엘리베이터 육교를 보여 드리고 CCTV는 지도에서 뺄게요. 맞으세요?" → "응" → "바꿨어요."
- **보는 점:** "엘베 있는 육교"를 사전(map_layer)으로 '엘리베이터 육교'에 맞춤. 확인 뒤 저장

## 8. 말뜻이 애매할 때 되묻기
- **누가·언제:** A
- **사용자:** "엘베 있는 데로 가자."
- **도구:** 없음 → 묻기
- **기대 답:** "지하철역 엘리베이터 출구 말씀이세요, 아니면 엘리베이터 있는 육교 말씀이세요?"
- **보는 점:** 짐작해서 길을 찾지 않음. 서버 응답의 ask 칸

## 9. 먼저 말 거는 비서 (알림)
- **누가·언제:** A, 월요일 8:20 (trip_habit: 월 8:30 국립아시아문화전당 2번), 맑음
- **사용자:** (말 안 함, 앱이 오늘 제안을 받음)
- **도구:** `get_my_info` → `recommend_trip(습관 목적지)`
- **기대 답 (알림):** "8시 반에 문화전당 가시죠? 오늘은 맑아서 걸어서 16분이에요. 지금 나가면 8시 46분에 도착해요."
- **보는 점:** 습관이 3번 이상일 때만 제안(시연 A는 3주치 기록이라 월 8:30이 3번). 걸음 속도(분당 46.9m)로 시간 계산

## 10. AI가 멈췄을 때 (대비)
- **누가·언제:** 아무나, 제미나이 응답 없음
- **사용자:** "남광주시장 가자."
- **도구:** 서버가 AI 없이 `search_place` → `recommend_trip`
- **기대 답:** 정해진 문장틀: "남광주시장까지 걸어서 ○분, 버스 ○분이에요. ○○이라서 ○○을 추천해요." + 버튼
- **보는 점:** AI가 없어도 추천이 나옴. 시연이 멈추지 않음
